Download every byte of the tag’s main flash, including firmware, settings and calibration data. Install a prepared application while preserving factory data. Everything runs locally in your browser.

Power the tag from 3.3 V with its batteries removed. Use short leads and a common ground.

The v1.4/v1.5/v1.6 bridge defaults to 2 Mbaud. Previous Python bench reads took about 30 seconds per 512 KiB pass at this rate; browser timing may differ. If verification fails, reconnect and select 1.5 Mbaud before choosing the serial port. With this option off, verification checks 256-byte samples every 64 KiB and at the end.

4. Flash an application .bin

Experimental: chip 026255 with EB6013 flash only. Choose the application .bin supplied for your tag. The tool builds its flash plan automatically; no JSON or extra binary files are needed.

No firmware selected.

Uncheck to skip saving the backup file. Two tag reads still run to preserve factory data and verify the write. Without a saved backup, recovery is limited to this open browser session.

For writes, select 1.5 Mbaud or 921600 baud before opening the SWS port. 2 Mbaud is for readback and read-only checks. The tool takes two matching full reads before allowing any erase. When backup saving is enabled, it also saves and rereads your recovery file before writing. It writes application sectors only, verifies the entire flash, and restores protection. Keep this page open and the tag powered through completion or recovery.

Cancellation after writing starts restores the original application. If recovery fails, the CPU stays halted; keep the saved backup and report. Firmware and recovery instructions.

5. Discovery progress and logs

Read status from our 437 D8/D9 discovery firmware over Bluetooth, or watch its live UART output. Status polling sends only the read-only discovery status command; it does not start, pause or confirm trials.
