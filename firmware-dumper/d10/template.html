Before you start: wiring and programmer

Use an RP2040 programmer running v1.6. If it already has v1.6, leave it as it is. Close other flashers and serial monitors.

Power the tag from 3.3 V with its batteries removed. Use short wires and a common ground.

Only SWS is used for data; UART wires are not needed. This is a normal installer. If an earlier installation failed and left the tag paused, use its recovery instructions first.

Programmer setup and wiring guide

1Connect the programmer

Plug the RP2040 into USB. Click below and choose it from the browser’s list.

Waiting for a programmer.

2Choose the tag port

Choose SWS (the first serial interface). If there are two ports, choose SWS, not “Tag UART”.

Connect the programmer first.

3Save a backup & install

Click below and choose where to save your backup. We’ll read the tag twice, save and check that backup, then install D10 and verify it. Temporary read and write failures get up to three attempts. Every backup attempt needs two fresh matching reads; writes are rechecked before retrying.

This page uses a slower 460800-baud connection. Reading and installation can take several minutes. Keep the page open, USB connected and tag powered until it finishes. This replaces the tag’s current application.

Activity and technical details

D10 discovery · experimental · page revision 2026-10-18.4. Supported 437 waveform banks: 0ASSPQ0NX, 0BNSPQ0UK and 0BNSPQ069. Installation uses the existing v1.6 writer at 460800 baud, up to three backup-read attempts, and up to three checked attempts per application sector. Retries stop if tag identity, protection or repeatable readback cannot be verified. Files stay on your computer. Browser tests use simulated devices; physical installation through this page remains unverified.
