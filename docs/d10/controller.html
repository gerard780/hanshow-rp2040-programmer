1. Watch the trials

Auto tries profiles 0–3 once. Each trial has a 60-second deadline covering both refresh passes, followed by 5 seconds to inspect the display before the next trial. Pause stops progression after the active trial finishes or times out and powers down safely.

A retained image can belong to an earlier attempt. Match the number on the screen, even when the controller has advanced. Wait for the panel to settle before judging it.

2. Try a promising profile again

Select starts confirmation image A; after you confirm A, the tag draws a different image B for a second confirmation. All candidates retain the detected factory waveform bank, voltages, GPIO mapping and byte-level CS framing.

3. Confirm the exact image you see

After a selected profile finishes its test, inspect all corners, text and white, black, red and yellow patches. Enter the attempt number printed on the physical display. Confirmation requires a fresh observation for each test image.

Use Chrome or Edge with Web Bluetooth on a supported computer. The page needs a secure context; opening the local file works in supporting browsers, or serve this folder at localhost. Linux Bluetooth support can depend on browser settings. Connection loss does not pause an automatic sequence: reconnect and read the status. D10 records trial events in its flash journal across restarts while space remains. The journal status shows whether new records can be saved; it does not confirm a visible image. This controller sends only discovery commands. Export session JSON saves this browser’s BLE messages; the persistent flash journal is a separate record.
